# Fraud & Risk Transaction Analysis

## Project Overview
This project uses SQL to analyze customer and transaction data in order to identify potential fraud and transaction risk patterns.

## Tools Used
- MySQL
- SQL
- GitHub

## Dataset
### customers
- customer_email
- customer_phone
- customer_device
- customer_ip_address
- customer_billing_address

### transactions
- transaction_id
- payment_method_type
- transaction_amount
- transaction_failed

## Key SQL Skills Used
- JOIN
- GROUP BY
- COUNT
- SUM
- CASE WHEN
- ORDER BY

## Business Questions
1. What is the transaction failure rate?
2. Which payment methods have higher failure rates?
3. Which customers show higher risk behavior?

## Conclusion
This project demonstrates how SQL can be used to analyze fraud and transaction risk patterns.
